# Competition / 电子设计竞赛

全国大学生电子设计竞赛相关资料，含历年赛题、项目实现和参考资源。

## 目录结构

```
├── 历年赛题/          2025年电赛赛题(A-H题) + 优秀作品 + 参考书
├── 激光云台/          二维激光云台项目（开源V2.0）
│   ├── 1.画圆（开环）/
│   ├── 2.激光打靶（闭环）/
│   ├── 3.识别矩形框/
│   ├── 4.电机选择/
│   ├── 5.3D打印件资料/
│   └── 6.五金配件购买/
├── 三相AC-DC/        2021真题B - 三相AC-DC变换电路
└── 体感云台/          DIY体感云台（ESP32 + 源码）
```

## 重点项目

- **激光云台**: 完整的电赛题目实现，从开环画圆到闭环打靶到视觉识别
- **体感云台**: ESP32 体感控制云台，含制作教程和接线图
