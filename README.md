# Hardware / 机械结构

3D 打印件和机械结构设计文件。

## 目录结构

```
3d-prints/
├── 丐版/          丐版机器人3D打印件（14个STL）
├── 装甲板灯罩/    RoboMaster 装甲板灯罩（STEP/SLDPRT）
└── 二维云台/      二维云台结构件（8个STL + 3mf）
```

## 使用说明

- STL 文件可直接用切片软件（Cura / PrusaSlicer / 拓竹）打印
- 3MF 文件用拓竹 Bambu Studio 打开
- STEP/SLDPRT 用 SolidWorks 或 FreeCAD 编辑
