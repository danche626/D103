# Hardware / PCB 设计

PCB 设计相关资料，包括证书练习、Gerber 工程文件和高性能电路板复刻项目。

## 目录结构

```
├── pcb-cert-exercises/    PCB Layout 工程师初级证书 - 练习题（7个项目）
├── pcb-cert-exam/         PCB Layout 工程师初级证书 - 模拟考试
├── gerber-files/          Gerber 工程文件（机械臂PCB）
├── high-perf-boards/      高性能电路板复刻
│   ├── H616/
│   ├── RK3588/
│   ├── STM32H750/
│   └── XC7A35T/
└── PCB设计经典资料_上_.pdf
```

## 内容说明

- **证书练习**: USB电流表、USB集线器检测板、Zigbee学习板、STM32G474/F405/U575开发板、电流输出板
- **高性能电路板复刻**: 涵盖 ARM (H616/RK3588)、STM32H750、FPGA (XC7A35T) 多平台
