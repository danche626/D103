## 仓库结构

```
├── 激光云台/
│   ├── README.md          ← 项目概述与快速部署
│   ├── docs/              ← 设计文档
│   │   ├── 系统设计.md    ← 架构、算法、控制策略
│   │   ├── 硬件布局.md    ← 物理布局方案
│   │   └── 接线指南.md    ← 完整接线说明
│   ├── src/               ← 源代码
│   │   ├── jetson/        ← Jetson部署程序
│   │   └── tools/         ← 调试工具
│   └── hardware/          ← 硬件相关说明
│       └── 原理图说明.md  ← 扩展板关键信息
└── README.md              ← 本文件
```
