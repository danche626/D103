# 扩展板原理图关键信息

## 扩展板型号

Jetson Nano Adapter V3.3

## GPIO 实际映射（原理图确认）

原理图中 40pin 排针网络标签与实际功能对照：

| 功能 | 网络标签 | 实际Pin | BCM编号 | 备注 |
|------|----------|---------|---------|------|
| KEY1 | GPIO20 | Pin 38 | BCM20 | 经过74HC126D缓冲器 |
| KEY2 | GPIO6 | Pin 31 | BCM6 | 经过74HC126D缓冲器 |
| BUZZER | BUZZER | Pin 33 | BCM13 | NPN三极管驱动 |
| LED1 | LED1 | — | — | 板载LED |
| 激光 | (自定义) | Pin 12 | BCM18 | 直接GPIO输出 |

## 74HC126D 三态缓冲器问题

扩展板上的 KEY1/KEY2 信号经过 74HC126D 三态缓冲器才连接到 Jetson GPIO。

问题：缓冲器 OE（使能）引脚未默认拉高，导致输出高阻态，GPIO 读不到按键状态。

实测结果：
- Pin 38 (KEY1/GPIO20): 始终读 0，按键无反应
- Pin 31 (KEY2/GPIO6): 始终读 0，按键无反应
- Pin 29 (IO5): 与KEY无关，同样读0

解决方案：绕过扩展板按键，外接物理按钮到 Pin 7（确认有上拉，读数为1）。

## 40pin 排针完整定义

```
左列(奇数)              右列(偶数)
Pin 1:  3V3            Pin 2:  5V
Pin 3:  SDA (I2C)      Pin 4:  5V        ★ 激光红线
Pin 5:  SCL (I2C)      Pin 6:  GND       ★ 激光黑线
Pin 7:  GPIO4 (GCLK)   Pin 8:  TXD       ★ 外接按钮
Pin 9:  GND            Pin 10: RXD       ★ 按钮GND
Pin 11: GPIO17         Pin 12: GPIO18    ★ 激光黄线
Pin 13: GPIO27         Pin 14: GND
Pin 15: GPIO22         Pin 16: GPIO23
Pin 17: 3V3            Pin 18: GPIO24
Pin 19: MOSI (GPIO10)  Pin 20: GND
Pin 21: MISO (GPIO9)   Pin 22: GPIO25
Pin 23: SCLK (GPIO11)  Pin 24: CE0 (GPIO8)
Pin 25: GND            Pin 26: CE1 (GPIO7)
Pin 27: ID_SD          Pin 28: ID_SC
Pin 29: GPIO5          Pin 30: GND
Pin 31: GPIO6          Pin 32: GPIO12
Pin 33: GPIO13         Pin 34: GND
Pin 35: GPIO19         Pin 36: GPIO16
Pin 37: GPIO26         Pin 38: GPIO20    (KEY1, 不可用)
Pin 39: GND            Pin 40: GPIO21
```

## I2C 设备

- MPU-6050 陀螺仪/加速度计（板载，本项目未使用）
- 无其他 I2C IO 扩展器

## 供电

- 扩展板 DC 口输入 5V → 通过 RT8289GSP DC-DC 稳压
- 支持 500mA 保险丝保护
