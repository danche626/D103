# 系统设计文档

## 1. 系统架构

```
┌─────────────┐     USB      ┌─────────────────────────┐    RS485     ┌───────────┐
│  USB Camera │────────────→ │  Jetson Nano + 扩展板    │────────────→ │ YL42M ×2  │
│  320×240    │              │  OpenCV + PID + Modbus   │              │ X轴 + Y轴 │
└─────────────┘              └──────────┬──────────────┘              └───────────┘
                                        │ GPIO Pin12 (TTL)
                                        ▼
                                  ┌───────────┐
                                  │ 405nm激光  │
                                  └───────────┘
```

## 2. 软件流程

```
开机自启 → 摄像头初始化 → 全屏显示
     ↓
主循环 → 读帧 → 灰度 → OTSU二值化 → 轮廓检测
     ↓
矩形筛选(面积/顶点/凸性/宽高比/内部亮度)
     ↓
目标质心 → 指数滑动平均(α=0.65) → 像素误差
     ↓
双环PID → 速度指令 → Modbus写入电机
     ↓
对准判定(连续5帧误差<8px) → 激光点亮
```

## 3. 识别算法

### 3.1 目标特征

- 黑色边框矩形（A4纸大小）
- 白色背景
- 使用 OTSU 自动阈值将黑白分离

### 3.2 识别流水线

```python
灰度图
  → cv2.threshold(0, 255, THRESH_BINARY + THRESH_OTSU)
  → cv2.findContours(RETR_TREE)
  → 面积过滤: 2% ~ 50% 画面
  → 多边形近似: approxPolyDP → 4顶点
  → 凸性检查: isContourConvex
  → 宽高比: max/min < 2.0
  → 内部亮度验证: mean > 180
  → 选最大面积 → 计算质心
```

### 3.3 抗干扰

| 措施 | 说明 |
|------|------|
| 面积跳变过滤 | 帧间面积比 0.4~2.5 倍才接受 |
| 指数滑动平均 | α=0.65，平滑位置抖动 |
| 丢帧 | grab()+read() 丢弃缓冲旧帧 |

## 4. 控制策略

### 4.1 双环 PID

```
外环(位置): target_v = Kp × error + Kd × d(error)/dt
内环(速度): output += 0.75 × v_err + Ki × ∫v_err
```

| 参数 | 值 | 作用 |
|------|----|------|
| Kp | 5.5 | 位置比例 |
| Kd | 1.0 | 位置微分，抑制过冲 |
| Ki_vel | 6.0 | 速度积分，消除静差 |
| MAX_SPEED | 650 | 输出限幅（65RPM）|
| DEADZONE | 8 px | 对准死区 |

### 4.2 电机速度模式

采用 Modbus 写寄存器 0x60（速度模式），非步进模式。

方向映射：
- X轴: err>0 → 负速度（电机左转追目标）
- Y轴: err>0 → 负速度（电机上转追目标）

### 4.3 软件限位

- Y轴上限: +55°，下限: -15°
- 通过积分电机速度×时间估算当前角度
- 到限时该方向速度强制为0

## 5. 激光控制

| 条件 | 动作 |
|------|------|
| X和Y误差均 < DEADZONE，连续≥5帧 | 点亮激光 |
| 任一帧偏离 | 立即关闭 |
| 目标丢失 | 关闭 |

控制方式：GPIO Pin12 输出 HIGH/LOW。

## 6. 通信协议

Modbus RTU, 115200baud, 8N1

### 速度模式写入

```
[addr][0x10][0x00][0x60][0x00][0x04][0x08]
[起始速度 2B][目标速度 2B][加速时间 2B][到位容差 2B]
[CRC16-Lo][CRC16-Hi]
```

### 停车

```
[addr][0x10][0x00][0x01][0x00][0x02][0x04]
[0x0000][0x0000][CRC]
```

优化：速度变化 < 5 时不发送，减少总线负载。

## 7. 激光偏移补偿

激光笔安装在摄像头正下方 4.5cm。目标参考点需上移补偿：

```
err_y = target_y - (center_y + LASER_OFFSET_Y)
LASER_OFFSET_Y = -25  (实测调整)
```

负值 = 参考点上移 = 云台多转一点使激光对准靶心。
