# 硬件布局方案

## 1. 整体布局原则

- 重心居中，避免云台负载偏心
- 激光笔与摄像头同轴对齐（上下排列）
- 电池放底部压低重心
- 显示屏朝向操作者

## 2. 云台顶部布局（随动部分）

```
          ┌─────────────────────────────┐
          │         摄像头 (顶部)        │
          │        ┌─────────┐          │
          │        │ ○ 镜头  │          │
          │        └─────────┘          │
          │            ↕ 4.5cm           │
          │        ┌─────────┐          │
          │        │ * 激光笔 │          │
          │        └─────────┘          │
          │                             │
          └──────────┬──────────────────┘
                     │ Y轴转轴
          ┌──────────┴──────────────────┐
          │       Y轴电机 (俯仰)        │
          └──────────┬──────────────────┘
                     │
          ┌──────────┴──────────────────┐
          │       X轴电机 (水平)        │
          └─────────────────────────────┘
```

### 关键尺寸

- 摄像头到激光笔中心距: **4.5cm**（垂直）
- 摄像头和激光笔必须在同一竖直平面内
- 两者固定在同一支架上，跟随Y轴旋转

## 5. 布局要点

### 5.1 重心考虑

| 组件 | 重量估算 | 布局位置 |
|------|----------|----------|
| Jetson + 扩展板 | ~150g | 底座一侧 |
| 电池1 (5V) | ~200g | 底座另一侧（配重）|
| 电池2 (12-24V) | ~300g | 底座中心偏低 |
| 摄像头+激光 | ~50g | 云台顶部 |
| Y轴电机 | ~350g | 云台中部 |
| X轴电机 | ~350g | 底座中心 |

### 5.2 显示屏

- 使用扩展板自带的 LCD 屏幕
- 屏幕朝向操作者方向
- 全屏显示摄像头画面 + 追踪状态叠加

### 5.3 走线规划

```
Jetson USB1 → USB-RS485 → 电机485总线
Jetson USB2 → 摄像头（或通过USB Hub）
Jetson Pin12 → 激光笔黄线
Jetson Pin4(5V) → 激光笔红线
Jetson Pin6(GND) → 激光笔黑线
电池1 → 扩展板DC口 → Jetson供电
电池2 → 电机VIN (两台并联)
电池1 GND ←→ 电池2 GND (共地线)
```

### 5.4 USB Hub 需求

如果摄像头 + RS485 同时插入 Jetson USB 口不稳定，使用带独立供电的 USB Hub。

## 6. 安装顺序

1. 底座板固定 X 轴电机
2. X 轴输出轴安装 Y 轴电机支架
3. Y 轴输出轴安装摄像头+激光支架
4. Jetson + 扩展板固定在底座
5. 电池组固定在底座（注意配重平衡）
6. 走线、扎线
7. 共地线连接
8. 上电测试
