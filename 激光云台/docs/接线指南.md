# 接线指南

## 1. 供电方案（双电源独立供电）

```
电源1 (Jetson)                   电源2 (电机)
DC 5V 4A                         DC 12-24V
    │                                │
    ▼                                ▼
┌──────────────┐              ┌──────────────────┐
│ 扩展板 DC口   │              │  YL42M X轴 VIN+  │
│ 给Jetson供电  │              │  YL42M X轴 GND   │
└──────────────┘              │  YL42M Y轴 VIN+  │
                              │  YL42M Y轴 GND   │
                              └──────────────────┘
```

**两个电源的 GND 必须共地！**

## 2. RS485 接线

```
USB-RS485模块 (LES26/CH340) → Jetson USB口
    ├── 485A (D+) ──┬── X轴电机 485A
    │               └── Y轴电机 485A
    └── 485B (D-) ──┬── X轴电机 485B
                    └── Y轴电机 485B
```

电机 Modbus 地址：X轴=0x01, Y轴=0x02

## 3. 激光接线

```
激光模块（405nm 10mW TTL）
    红线 → Pin 4 (5V)
    黑线 → Pin 6 (GND)
    黄线 → Pin 12 (GPIO18, TTL信号)
```

Pin 12 位置（40pin排针左列第6个）：
```
 1(3V3)  2(5V)      ← 靠近DC口
 3(SDA)  4(5V)      ★ 激光红线
 5(SCL)  6(GND)     ★ 激光黑线
 7       8(TXD)
 9(GND)  10(RXD)
 11      12(GPIO18) ★ 激光黄线
```

## 4. 外接按钮（启停开关）

扩展板板载 KEY1 因 74HC126D 缓冲器隔断不可用，需外接按钮：

```
Pin 7 (GPIO4, 有内部上拉=1) ── 按钮一端
Pin 9 (GND)                 ── 按钮另一端
```

按下按钮 → Pin7 从 1 变 0 → 程序检测到边沿 → 切换追踪状态

## 5. 完整接线总览

```
                ┌─────────────────────────────────────┐
                │       Jetson Nano + 扩展板 V3.3      │
                │                                     │
 DC 5V 4A ────→│ 扩展板DC口                           │
                │                                     │
 USB摄像头 ────→│ USB口1                               │
 USB-RS485 ────→│ USB口2                               │
                │                                     │
                │ Pin 4 (5V)  ────→ 激光红线           │
                │ Pin 6 (GND) ────→ 激光黑线           │
                │ Pin 12      ────→ 激光黄线(TTL)      │
                │                                     │
                │ Pin 7  ─────────→ 外接按钮(启停)     │
                │ Pin 9 (GND) ────→ 按钮另一端         │
                │                                     │
                │ [屏幕] 全屏显示摄像头追踪画面         │
                └─────────────────────────────────────┘

 DC 12-24V ──┬──→ X轴 YL42M (VIN, GND)  addr=0x01
             └──→ Y轴 YL42M (VIN, GND)  addr=0x02

 USB-RS485 ──┬──→ X轴 YL42M (485A, 485B)
             └──→ Y轴 YL42M (485A, 485B)

 ★ 电机GND 与 Jetson GND 共地
```

## 6. 注意事项

1. 先接线再上电，不要带电插拔485线
2. 共地很重要，不共地485通信不稳定
3. 激光安全：405nm对眼睛有害，避免直视
4. USB供电不足时用带独立供电的USB Hub
5. 电机电压：YL42M支持9-36V，推荐12V，电流≥1A/台
